# QUEUE — live dispatch state

One row per gate, newest at the bottom. See `README.md` for the loop.

**Statuses**

| Status | Meaning | Set by |
|---|---|---|
| `QUEUED` | Prompt written and dispatched to the operator; the box has not started it. | advisor |
| `APPROVED` | Advisor and operator agreed at the daily ferry that this gate may actually run. **It is the only status `wrought-runner` will start**, and every prompt it runs must carry an `ALLOWED-TOOLS:` header or the runner halts. Canonical: `docs/EXECUTOR-RAILS.md` §12. | advisor + operator |
| `RUNNING` | Box has archived the prompt to `prompts/` and is running it in a fresh context. | box |
| `BUNDLED` | Box has pushed `bundles/<GATE-NAME>/` and the gate is awaiting review. | box |
| `ADJUDICATED` | Advisor has reviewed the bundle; the gate is closed and the next one queued. | advisor |
| `RESET` | Gate started but produced no bundle. Partial evidence preserved, residue cleaned; it must be **re-dispatched fresh**. A terminal status — never left `RUNNING`. | box |
| `FOLDED INTO <gate>` | Gate never ran as its own session; its items were completed inside another gate, which names it. Terminal. | box |
