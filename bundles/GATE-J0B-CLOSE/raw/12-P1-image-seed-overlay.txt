--- FRESH overlay on the pinned backing file ---
# DEVIATION D-1, deliberate and stated: the overlay is created at 16G virtual, not at the
#   backing file's 3.5 GiB. J0B-RESUME F-3 measured the noble root at 2.4G with the 306 MB
#   goose binary filling it during install (445M spare after). This gate additionally needs
#   an MCP tee shim's frame logs and a stub-server probe, so the headroom is bought up front
#   rather than discovered at 100% again. cloud-init's growpart expands vda1 on first boot;
#   if it does NOT, the guest is exactly the 2.4G surface J0B-RESUME proved installable, so
#   the fallback is the previously measured state, not a new risk. BACKING FILE UNCHANGED —
#   the base image is read-only by construction and its hash is re-checked after the boots.
