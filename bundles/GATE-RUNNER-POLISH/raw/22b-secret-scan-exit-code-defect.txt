# GATE-RUNNER-POLISH raw/22b — CORRECTION BY ADDITION to raw/22 (rails §4), and a real defect
# date: 2026-08-29T13:42:02Z

RAW/22'S CLOSING VERDICT WAS WRONG WHEN IT WAS WRITTEN, AND THE PROBE IN THE SAME FILE PROVES IT.
It asserts "an unprivileged invocation REFUSES (exit 2)". The measurement three lines above it
shows a PermissionError TRACEBACK and `exit code: 1`. The verdict line was written from intent;
the probe measured behaviour, and behaviour won. raw/22 is left standing per rails §4.

THE DEFECT IT CAUGHT, in this gate's OWN new tool, and it is not cosmetic. Exit 1 is this tool's
code for "A SEALED CREDENTIAL IS IN THE STAGED DIFF". Exit 2 is "the scan could not run". Letting
the PermissionError escape collapsed the second into the first, so a caller that gates on the exit
code would have reported a LEAK where there was only a missing sudo. Loud in the wrong direction is
still wrong: an operator who sees "secret found" on a clean diff learns to distrust the tool.

FIXED: load_secrets_from_credstore() catches PermissionError and returns it as a problem, which
main() renders as the FAIL-to-scan message and exit 2.
